## Root Cause Analysis

### Primary Blocker: File Upload Restrictions

The Claude Code sandbox environment has fundamental security restrictions that prevent:

1. **Browser file picker interaction**: Cannot trigger or interact with native file chooser dialogs
2. **Playwright file upload**: Requires an open file chooser dialog to work
3. **Network file operations**: curl/wget blocked for security
4. **Python file operations**: urllib/requests operations not permitted
5. **File protocol access**: file:// URLs blocked with NetworkError
