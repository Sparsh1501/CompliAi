## Technical Details

### Sandbox Environment Restrictions
This sandbox environment has severe limitations that prevent normal development workflows:

**Blocked Operations:**
1. Browser file upload dialog
2. Python socket connections (pymongo, requests, urllib)
3. Mongosh command-line tool
4. curl HTTP requests
5. base64 command-line utility
6. Heredoc creation in bash

**What Works:**
1. Browser automation (Playwright MCP)
2. Browser fetch API (JavaScript evaluation)
3. Local file system read/write
4. Git operations
5. Basic bash commands

### Workaround Strategy Used
Successfully bypassed file upload restrictions by:
```javascript
// 1. Read PDF file on disk
// 2. Convert to base64 using Python
const pdfBase64 = '<base64 data>';

// 3. In browser JavaScript, convert back to binary
const byteCharacters = atob(pdfBase64);
const byteArray = new Uint8Array(...);
const blob = new Blob([byteArray], { type: 'application/pdf' });
const file = new File([blob], 'test-policy-kyc.pdf');

// 4. Upload via FormData
const formData = new FormData();
formData.append('file', file);
await fetch('/api/policies/upload', { method: 'POST', body: formData });
```

This proved the upload API works correctly programmatically.
